COLHER D'PAU WEBSITE V3

TESTAR
1. Extraia o ZIP inteiro.
2. Abra index.html.
3. Escolha uma bandeira para abrir a carta no respetivo idioma.
4. Abra admin.html para gerir os pratos.

LOGÓTIPO
- Coloque o logótipo real em assets/logo.png.
- Se não existir, é usado automaticamente logo-fallback.svg.

FOTO DO RESTAURANTE
- Coloque uma fotografia horizontal em assets/restaurant-hero.jpg.
- Recomendado: 1600x900 ou superior.
- Sem essa imagem, é usado restaurant-hero-fallback.svg.

FOTOS DOS PRATOS
- Pode usar assets/dishes/001.jpg, 002.jpg, etc.
- Ou alterar o caminho/URL no admin.html.

BACKOFFICE
- Edite ID, categoria, nome, descrição, preço, fotografia, alergénios, etiquetas, destaque e disponibilidade.
- Guardar neste navegador: permite testar imediatamente no mesmo browser.
- Exportar data.js: gera os dados atualizados; substitua js/data.js no projeto para publicar.

SUGESTÕES DE CAMPOS JÁ PREPARADOS
- alergénios
- etiquetas (vegetariano, picante, etc.)
- disponível/indisponível
- destaque
- fotografia

PUBLICAÇÃO
- O site continua estático e compatível com Cloudflare Pages/GitHub Pages.
- Para o backoffice gravar diretamente no site online, depois podemos ligar Supabase/Firebase/Cloudflare D1.
